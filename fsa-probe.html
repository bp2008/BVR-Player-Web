Directory iteration cost by folder size

This diagnostic needs a Chromium browser. It measures showDirectoryPicker() and FileSystemDirectoryHandle — the WICG File System Access API, implemented in Chrome, Edge and Opera and in no other engine. There is nothing to measure here in Firefox or Safari, because the thing being measured does not exist in them.

The player itself does not depend on any of it. It feature-detects and falls back to <input webkitdirectory>, which is in the HTML Standard and works everywhere. Only this diagnostic is Chromium-only.

Each run commits Chrome to enumerating the whole folder. Sampling only the first few thousand entries does not change that — dropping the iterator has been shown not to stop the work. The run itself is quick; the browser stays busy afterwards for however long the rest of the folder takes.

So far, all on the same SMB share, folders of empty files: 500 / 2,000 / 8,000 / 30,000 all cost ~0.48 ms an entry, while Aux1 at 223,000 costs 10–25 ms. The threshold is somewhere between 30,000 and 223,000 — or the variable is not size at all, since Aux1 is also being written to continuously and holds real 20 MB files rather than empty ones.

Grow one folder and re-probe after each step, stopping at the first size that goes bad — that finds the threshold and keeps the worst-case grinding as short as possible. Run it on peanut itself if you can: over SMB each file costs a network round trip, locally it is about a quarter of a millisecond. 

function Grow-TestFolder {
  param([string]$Path, [int]$Target)
  New-Item -ItemType Directory -Force $Path | Out-Null
  $have = 0
  foreach ($f in [IO.Directory]::EnumerateFiles($Path)) { $have++ }
  if ($have -ge $Target) { "already has $have files"; return }
  $sw = [Diagnostics.Stopwatch]::StartNew()
  ($have + 1)..$Target | ForEach-Object { [IO.File]::WriteAllBytes("$Path\f$_.bvr", @()) }
  "{0} files (+{1}) in {2:n1}s" -f $Target, ($Target - $have), $sw.Elapsed.TotalSeconds
}

# re-run with 60000, then 120000, then 223078, probing in between
Grow-TestFolder -Path '\\peanut\e\BlueIris\fsatest' -Target 60000
